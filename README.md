# LotusTelco Dialer

React Native VoIP dialer app for LotusTelco Inc.

## Setup

1. Install dependencies:
```
npm install
```

2. Add your logo to `src/assets/logo.jpg`

3. Build for Android:
```
eas build --platform android
```

## SIP Configuration
Edit `src/config/sip.ts` to update server settings.

## Package
- Android: `com.lotustelco.inc`
- iOS: `com.lotustelco.dialer`
